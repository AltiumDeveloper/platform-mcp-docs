# Repository documents

Documents for the people who maintain this repository. None of it is published.

- [Contributing](CONTRIBUTING.md): how to propose a change and what a pull request needs.
- [Security](SECURITY.md): how to report a security issue.
- [Open issues](OPEN-ISSUES.md): unknowns and things to confirm before they go into page text.
- `plans/`: working plans, in Markdown or HTML. The folder is gitignored; never commit a plan.
