# Changelog

What changed in the Altium 365 MCP Server, newest first. Altium updates the server for you, so there is nothing to
install; the [Tool reference](./tools/index.md) always describes the current release.

## First release

The server at `https://mcp.altium.com`, with sign-in through your Altium account and these tools:

- **[Platform](./tools/platform.md):** `a365_platform_workspace_list`
- **[Design](./tools/design.md):** `a365_design_project_list`, `a365_design_project_details`, `a365_design_projectvariant_list`, `a365_design_projecthistory_list`, `a365_design_projecthistory_details`
- **[Schematic](./tools/schematic.md):** `a365_schematic_summary_details`, `a365_schematic_script_run`, `a365_schematic_screenshot_capture`, `a365_schematic_object_highlight`, `a365_schematic_diff_details`, `a365_schematic_variantdiff_details`
- **[Collaboration](./tools/collaboration.md):** `a365_collaboration_commentthread_list`, `a365_collaboration_commentthread_create`, `a365_collaboration_commentthread_resolve`, `a365_collaboration_commentthread_delete`, `a365_collaboration_comment_list`, `a365_collaboration_comment_details`, `a365_collaboration_comment_create`, `a365_collaboration_comment_delete`
